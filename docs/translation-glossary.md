# Translation glossary

The getting-started site is published in English, French, Spanish,
Portuguese and Swahili. English is the source. The other four were
written by machine and **have not yet been reviewed by a fluent speaker**;
each page says so until its language is marked reviewed.

This file is where a reviewer starts. It lists the terms the translations
use, so that one thing has one name, and says where each translation came
from:

- **EarthRanger**: EarthRanger's web app already shows this word in the
  language. A reader will see the same word there.
- **SMART 7.5.6**: SMART Desktop 7.5.6's own interface files have this
  text in the language. A reader whose SMART runs in that language sees it
  on screen.
- **not from a product**: neither product has it. The translation is the
  machine's choice and most needs a reviewer's eye.

To correct a page, and to mark a language reviewed, see "The
getting-started site" in [`web/DEPLOY.md`](../web/DEPLOY.md). If you change
a term here, change it in the pages too.

Portuguese follows the Brazilian usage of both products (*arquivo*,
*usuário*, *senha*).
